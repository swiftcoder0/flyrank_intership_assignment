This study measured whether five March 2026 Google Search performance signals could identify content pages likely to experience a greater than 20% decline in Google Search impressions the following month. A Random Forest classifier was trained on 84,384 client-level holdout observations and evaluated on 16,509 test observations using Precision@100 as the primary decision-relevant metric. The model produced a directional signal above the 40.2% test-set base rate, but did not outperform a simple average search-position baseline. The result is presented as decision-support for a human review queue, not as a production refresh-recommendation system.

02 — RESEARCH QUESTION

Research Question

Can we identify content pages that are likely to experience a significant decline in Google Search impressions in the future?

The model produces a ranking of pages according to predicted probability of the defined decline outcome. This ranking can be used as a review queue for prioritizing further investigation. It does not prove that a page needs refreshing, and it does not establish that refreshing a page would improve performance.

04 — METHODOLOGY

Methodology

DECISION WINDOW
March 2026
Five features collected per page
OUTCOME WINDOW
April 2026
Impression decline measured

Features (March 2026): search impressions, search clicks, click-through rate, average search position, number of active days.

Target: 1 if April impressions < 80% of March impressions (a decline greater than 20%), else 0.

Split: client-level holdout — 84,384 training observations, 16,509 test observations — so pages from the same client were not distributed across both sets.

Model: RandomForestClassifier, 200 trees, class weighting balanced, random_state 42.

06 — LIMITATIONS

Limitations

01

Single time window

March predicts April; one month-to-month window cannot establish generalization across time.

02

Limited feature set

Only five Search-performance features were used; seasonality, demand, competition, content changes, and external events are not modeled.

03

No causal explanation

The target is an observed impression decline; it does not explain why the decline happened.

04

No refresh-effect measurement

The analysis does not measure whether refreshing a page causes performance improvement.

05

Did not beat baseline

The Random Forest did not outperform the simple average-position baseline.

06

Stability untested

Additional time windows would be required to assess stability and generalization.

07

Anonymized scope

The dataset is anonymized; the analysis does not attempt to identify individual clients or websites.
